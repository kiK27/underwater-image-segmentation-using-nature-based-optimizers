# underwater-image-segmentation-using-nature-based-optimizers

Underwater Image Segmentation with Metaheuristic Hyperparameter Optimization

A semantic segmentation pipeline for the SUIM dataset using a lightweight Tiny-U-Net, where SGD hyperparameters (learning rate, momentum, weight decay) are tuned using nature-inspired metaheuristic algorithms.

**Optimizers Compared**

Baseline SGD, DE, PSO, CMFO, GA, WOA, GWO, SSA

**Dataset**

SUIM — 8-class pixel-level underwater imagery annotations

**Requirements**

pip install torch torchvision numpy pillow scikit-learn matplotlib mealpy
